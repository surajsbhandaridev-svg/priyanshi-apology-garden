# A Thousand Flowers of Sorry — Dedicated to Priyanshi 💜

"A little world, made especially for Priyanshi."

Welcome to **A Thousand Flowers of Sorry**, a photorealistic, cinematic, and interactive digital garden built as a heartfelt apology and sanctuary. Designed around real botanical references of lavender fields and climbing roses at golden twilight, this experience offers a serene escape filled with wind movement, glowing fireflies, synchronized lyrics, and 50 unique messages written with genuine thought and respect.

---

## 🌸 Visual Experience & Features

1. **Photorealistic 2.5D Environment**: Inspired directly by custom garden photography—featuring winding flagstone paths, lush purple lavender fields, a illuminated wooden gazebo, stone archways, and soft evening mist.
2. **Interactive Wind & Particle Canvas Overlay**: Physics-driven fireflies that drift organically across the screen, sways in the breeze, and responds to mouse cursor depth parallax.
3. **6 Story Chapters**:
   - **Chapter I: The Entrance** — A cinematic reveal overlay welcoming Priyanshi.
   - **Chapter II: The Flower Path** — Interactive glowing flower nodes on the path that reveal secret floating notes when clicked.
   - **Chapter III: Little Things I Wanted You to Know** — An interactive card deck containing **50 original, deeply sincere, mature apology & appreciation messages**, along with a formal handwritten letter scroll.
   - **Chapter IV: The Garden Melody** — Integrated glassmorphic music player with full volume, progress seeking, and synchronized LRC lyrics for Justin Bieber's *Sorry*.
   - **Chapter V: The Quiet Sanctuary** — Environmental controls to adjust breeze speed, firefly density, and toggle between **Golden Dusk** and **Moonlit Violet Night**.
   - **Chapter VI: The Final Bouquet** — An emotional climax featuring a high-definition bouquet of lavender and pink roses, heartfelt closing poetry, and a final blooming flower blessing.

## 🎵 Audio & LRC Setup Instructions

1. **Audio File (`assets/sorry.mp3`)**:
   - Place your official `sorry.mp3` file inside the `assets/` directory named exactly `sorry.mp3`.
2. **Synchronized Lyrics (`assets/sorry.lrc`)**:
   - The timestamped lyrics file is pre-configured and included in `assets/sorry.lrc`.
3. **Browser Autoplay Note**:
   - Modern web browsers block unprompted audio autoplay. The opening screen ("Enter Your Garden 🌷") serves as an intentional user interaction that seamlessly begins music playback upon entry.

## 🚀 How to Host on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and create a new public repository named `priyanshi-apology-garden`.
2. **Upload Files**:
   - Upload the `index.html`, `README.md`, and the entire `assets/` folder to the repository root.
3. **Enable GitHub Pages**:
   - Go to **Settings** > **Pages**.
   - Under **Source**, select `Deploy from a branch` and choose `main` / `root`.
   - Click **Save**.
4. **Share the Link**:
   - In a few moments, GitHub will provide a live URL (e.g., `https://username.github.io/priyanshi-apology-garden/`). Share this link with Priyanshi!
